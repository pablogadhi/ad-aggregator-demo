# Component playbook

Recommended approach per technology, so components built on demand stay consistent. These are
starting points researched in Sept 2026 — **verify current versions and docs when building**
(context7 / official docs), and update the row with anything you learn.

| Component         | Status | Approach                                                                                                                                                                                                                        | Notes / gotchas                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **postgres**      | built  | CloudNativePG operator (chart `cnpg/cloudnative-pg`), `Cluster` CR                                                                                                                                                              | ha = 3 instances, anti-affinity on zone. `-rw`/`-ro` services = primary/replicas. Sync replication is a spec switch. **Instances:** `install.sh <profile> <instance>` renames Cluster/PodMonitor/secret (`<instance>-conn`) by piping `kubectl kustomize` through `sed` — two clusters per design work (ad-aggregator). `JDBC_URL` key for Flink/JVM clients. |
| **kafka**         | built  | Strimzi operator 1.2.0 (API `kafka.strimzi.io/v1`, Kafka 4.3.1, KRaft only), one `KafkaNodePool` of dual-role nodes + `Kafka` CR; topics as `KafkaTopic` CRs | ha = 3 dual-role nodes, zone `topologySpreadConstraints` (DoNotSchedule) + `rack.topologyKey: topology.kubernetes.io/zone` (replicas in 3 zones, `RackAwareReplicaSelector`). Built-in `kafkaExporter` gives per-partition offsets / group lag; JMX rules from Strimzi's `kafka-metrics.yaml`. v1 API: no `strimzi.io/node-pools`/`kraft` annotations, `metadataVersion` required-ish (pin `4.3-IV0`). `auto.create.topics.enable=false`. Kafka 4.x console tools: `--command-property`/`--reader-property` (old `--producer-property`/`--property` are deprecated). `kafka-configs --describe --all` prints each key twice (value + synonyms). UI (kafbat) not built yet. |
| **redis**         | built  | Official `redis:8.8.3` StatefulSet + `redis_exporter` sidecar; `install.sh` bootstraps Redis Cluster itself (no operator)                                                                                                   | Chosen over the OT redis-operator to control zone placement and survive all-pods restarts: nodes announce their headless FQDN (`cluster-announce-hostname` + `cluster-preferred-endpoint-type hostname`) and `start.sh` rewrites `nodes.conf` IPs from DNS on boot (`publishNotReadyAddresses`). Bootstrap: `--cluster create` 3 primaries (one per zone) with **IPs** (MEET needs IPs), then `--cluster add-node --cluster-slave` choosing the replica↔primary permutation with fewest same-zone pairs (a greedy pick can leave the last pair in one zone). `cluster-require-full-coverage no`. `persistentVolumeClaimRetentionPolicy: Delete` so uninstall resets state. |
| **elasticsearch** | todo   | ECK operator (Elastic Cloud on Kubernetes, free Basic license), `Elasticsearch` + `Kibana` CRs                                                                                                                                  | Needs `vm.max_map_count>=262144` on the Docker VM (Docker Desktop: already 262144). small = 1 node, 1Gi heap; ha = 3 nodes with zone awareness (`node.attr.zone`). Default is TLS + auth: expose `URL` with https and the elastic user in the conn secret, or disable TLS on http for the lab.                                                                                                                                                     |
| **cassandra**     | todo   | cass-operator (K8ssandra), `CassandraDatacenter` CR                                                                                                                                                                             | Requires cert-manager (installed by the platform). One rack per zone. Cassandra is memory-hungry: small = 1 node 1Gi heap. Python driver: `cassandra-driver` (`LOCAL_DC` must match).                                                                                                                                                                                                                                                              |
| **flink**         | built  | Apache Flink Kubernetes Operator 1.16.1 (helm repo `archive.apache.org/dist/flink/flink-kubernetes-operator-<v>/` — downloads.apache.org drops old releases) | Watches `apps` (`watchNamespaces`), job SA `flink`. Jobs on **Flink 2.2.1** (`flink:2.2.1-scala_2.12-java17`, `flinkVersion: v2_2`): newest Flink with both Kafka (5.0.0-2.2) and JDBC (4.1.0-2.2, split into `-core` + `-postgres`) connector releases, though the operator already supports up to v2_4. Flink 2 keys: `execution.checkpointing.dir` (not `state.checkpoints.dir`). S3 on Floci works with `ENABLE_BUILT_IN_PLUGINS=flink-s3-fs-presto-2.2.1.jar` + `s3.endpoint`, `s3.path.style.access: "true"`. Operator default config adds a Prometheus reporter (9249) to every job; PodMonitor relabels a declared port to 9249 because Flink pods don't declare it. Autoscaler built in; `jobmanager.scheduler: adaptive` for in-place rescale. |
| **temporal**      | todo   | `temporalio/helm-charts` using CNPG Postgres for persistence (create `temporal` + `temporal_visibility` DBs via CNPG `Database` CRs). `lite` profile: single `temporalio/temporal` dev-server pod (`temporal server start-dev`) | UI at `temporal.localhost`. Workers are regular services (kind: worker) using the `temporalio` Python SDK with `TEMPORAL_ADDRESS`.                                                                                                                                                                                                                                                                                                                 |
| **aws**           | built  | **Floci** 2.1.0 (MIT, no account, LocalStack-compatible port 4566) as Deployment + PVC; **MiniStack** as fallback                                                                                                                     | LocalStack needs an account + auth token since 2026.03 (free tier non-commercial); MinIO OSS is archived — avoid both. `FLOCI_STORAGE_MODE=persistent` + PVC; health at `/_localstack/health`. Verified: S3 path-style put/get, multipart (ETag `-N`), SQS, Flink checkpoints via `flink-s3-fs-presto`. The `amazon/aws-cli` image has no `cmp` (use `md5sum`). Conn keys map 1:1 onto `AWS_*` env vars the SDKs read. |

## Real AWS (only when emulation isn't enough)

New accounts (since Jul 2025): $100 credit + up to $100 more; the _Free plan_ can't be billed and closes
after 6 months / when credits run out. Always-free: Lambda 1M req, SQS 1M req, SNS 1M publishes,
DynamoDB 25 GB (S3 is paid from credits). Add a Zero-Spend budget. Components never require it.
